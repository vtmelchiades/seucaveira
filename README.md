## cyber-doctor (赛博华佗)

O projeto [cyber-doctor](https://github.com/ZeroTang05/cyber-doctor) está instalado em
[`cyber-doctor/`](cyber-doctor/) com ambiente virtual próprio (`.venv/`).

Instruções completas: [`cyber-doctor/INSTALL.pt-BR.md`](cyber-doctor/INSTALL.pt-BR.md)

```bash
# configure as chaves de API em cyber-doctor/.env e rode:
cd cyber-doctor && ../.venv/bin/python launch.py   # http://localhost:7860
```
